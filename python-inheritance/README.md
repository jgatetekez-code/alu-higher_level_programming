This project focuses on understanding inheritance in Python. 
Inheritance allows a class (child/subclass) to reuse attributes and methods from another class (parent/superclass).

Through this project, we learn how classes can inherit from other classes, how to override inherited methods and attributes, and how Python handles relationships between classes.

## Learning Objectives

By completing this project, I learned:

- What a superclass, base class, or parent class is.
- What a subclass is.
- How to inherit a class from another class.
- How to use multiple inheritance.
- How to override methods and attributes inherited from a parent class.
- How to use `super()` to access parent class methods.
- How to use `isinstance()`, `issubclass()`, and `type()`.
- How Python determines available attributes and methods through inheritance.
