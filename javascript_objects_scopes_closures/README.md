# JavaScript - Objects, Scopes and Closures

This project covers the basics of objects, classes, scopes, and closures in JavaScript, using Node.js.

## Learning Objectives

- How to create an object in JavaScript
- What `this` refers to
- What `prototype` means
- How to inherit an object from another
- What a closure is and how to use it
- What the difference is between `var`, `let`, and `const`
- How to use the `class` notation to define classes

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Files are interpreted on Ubuntu with Node.js
- All files end with a new line
- The first line of every file is `#!/usr/bin/node`
- Code follows the `semistandard` style
- Files must be executable
