A beginner-level project introducing the basics of JavaScript: variables, data types, and simple scripts run directly from the command line using Node.js.

## Description

This project is part of the ALU Higher Level Programming curriculum. It covers fundamental JavaScript concepts such as:

- Declaring variables with `const` and `let`
- Understanding data types (no native `Dictionary` type — JavaScript uses `Object`)
- Writing and executing simple scripts with `console.log`
- Following JavaScript style guidelines using `semistandard`

## Requirements

- All scripts run on Ubuntu 20.04 LTS using `Node.js 12.x.x`
- All files end with a new line
- Code follows the `semistandard` style guide (no linting errors)
- All files must be executable (`chmod +x`)
- All files start with `#!/usr/bin/node`
- The length of your files will be tested using `wc`
