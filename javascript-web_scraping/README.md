This project covers working with JSON data, making HTTP requests, and reading and writing files in Node.js.

## Learning Objectives

- Why JavaScript programming is amazing
- How to manipulate JSON data
- How to use the `request` module and the fetch API
- How to read and write a file using the `fs` module

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Files are interpreted on Ubuntu with `node`
- All files end with a new line
- The first line of every file is `#!/usr/bin/node`
- Code follows the `semistandard` style
- All files must be executable
- `var` is not allowed
