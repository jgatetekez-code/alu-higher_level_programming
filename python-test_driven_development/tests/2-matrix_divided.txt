The ``matrix_divided`` function
===============================

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Divide a matrix by an integer:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 2)
    [[0.5, 1.0, 1.5], [2.0, 2.5, 3.0]]

Divide a matrix by a float:

    >>> matrix = [[2, 4], [6, 8]]
    >>> matrix_divided(matrix, 2.0)
    [[1.0, 2.0], [3.0, 4.0]]

Original matrix is unchanged:

    >>> matrix = [[1, 2], [3, 4]]
    >>> new_matrix = matrix_divided(matrix, 2)
    >>> matrix
    [[1, 2], [3, 4]]
