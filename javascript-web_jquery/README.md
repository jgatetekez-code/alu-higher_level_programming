# JavaScript - Web jQuery

This project covers manipulating web pages with JavaScript and jQuery in the browser: selecting HTML elements, changing styles and content, handling events, and fetching data with AJAX, without reloading the page.

## Learning Objectives

- Why jQuery makes front-end programming easier
- How to select HTML elements with JavaScript and with jQuery
- The differences between `ID`, `class`, and `tag name` selectors
- How to modify an HTML element's style
- How to get and update an HTML element's content
- How to modify the DOM
- How to make `GET` and `POST` requests with jQuery AJAX
- How to listen and bind to DOM events and user events

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Files are interpreted in Chrome (version 57.0)
- All files end with a new line
- Code follows the `semistandard` style: `semistandard *.js --global $`
- jQuery version 3.x only
- `var` is not allowed
- The HTML must not reload for each action (DOM manipulation, updating values, fetching data)
